# Knowledge-Graph-for-Lung-Cancer-Diagnosis-and-Treatment


🔹 PROJECT 4: Knowledge Graph for Lung Cancer Diagnosis

📘 Project Overview

This project focuses on constructing a semantic knowledge graph to represent complex relationships among diseases, symptoms, diagnostic tests, and treatments related to lung cancer.
________________________________________

🔬 Core Components

•	Ontology design using OWL

•	Knowledge extraction from medical sources

•	Semantic relationship modeling

________________________________________
🧠 Tools & Technologies

•	WebProtégé

•	RDF / OWL

•	SPARQL

________________________________________
📊 Outcomes

•	Enabled structured representation of medical knowledge

•	Improved semantic querying and relationship discovery

•	Enhanced decision-support capabilities in clinical contexts

________________________________________
📌 Example Queries

•	What symptoms are associated with lung cancer?

•	Which treatments correspond to specific diagnoses?

•	What diagnostic tests confirm particular conditions?
